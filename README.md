## Projetos

### 🏎️ TurboX
Simulador de preparações automotivas com sistema completo de upgrades, mais de 200 peças e cálculos de performance em tempo real. Inclui autenticação, gerenciamento de usuários/carros e API REST própria com 16 marcas suportadas.
**Stack:** Next.js 15, React 19, Axios
🔗 [Repositório](https://github.com/PedroLeoo07/turboX-front-end) · [Demo](https://turbo-x-front-end.vercel.app)

### 🏪 Barbershop Management
Sistema de gestão para barbearias com autenticação JWT, controle de acesso por papéis (RBAC) e tratamento de concorrência em SQL — o projeto mais arquiteturalmente elaborado do portfólio.
**Stack:** TypeScript, CSS
🔗 [Repositório](https://github.com/PedroLeoo07/barbershop-management-web)

### 🎮 PlayStation API
Interface para consumir e exibir dados de jogos, consoles e serviços da PlayStation Store.
**Stack:** Next.js, JavaScript, Tailwind CSS
🔗 [Repositório](https://github.com/PedroLeoo07/playstation-api) · [Demo](https://api-playstation.vercel.app)

### 🎮 Xbox API
API REST para consumo e análise de dados do Xbox, com foco em estatísticas de jogadores e jogos.
**Stack:** TypeScript, Next.js
🔗 [Repositório](https://github.com/PedroLeoo07/xbox-api)
